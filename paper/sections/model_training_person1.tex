\subsection{Proposed Model and Training}
The shared configuration uses a two-layer temporal CNN with 64 channels and kernel width 3, followed by one four-head attention encoder, a feed-forward width of 128, and a three-class classification head. The attention head width is 16. Dropout is 0.1. The model outputs logits and is trained using AdamW with learning rate $10^{-3}$, weight decay $10^{-4}$, and batch size 64. Cross-entropy class weights are calculated from the training split only. The checkpoint with the best validation macro-F1 is selected, with early stopping after five epochs without improvement and at most 30 epochs. Runs use seeds 42, 43, and 44; all models must use the same data split and protocol. Record any changes to these defaults in the final report.
